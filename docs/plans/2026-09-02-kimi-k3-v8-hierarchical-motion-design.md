# Kimi K3 第八版层级动画设计

## 目标

根据用户拖动原片时间轴后的观察，修正第七版“元素分别摆上去”的问题。第八版不追求像素级复刻，但必须还原真实的运动层级：整个文字内容先作为一个父级模块从左向右进场，父级内部的标题、高亮、辅助文字和正文再播放各自的局部动效。

## 方案比较

1. 给第七版每个元素复制同一条横移动画：改动最小，但数据上仍是一堆独立元素，后续调整容易再次失去同步。
2. 扩展结构化 JSON：增加父级分组、富文本标题、逐字正文和纹理高亮。改动适中，能继续作为可复用 Skill 模板。采用此方案。
3. 单独编写专用 TSX：最容易针对本镜头精修，但会绕开通用 JSON 链路，不利于未来素材库复用。

## 结构

```text
text-group（整组从左向右进入）
├── title-module
│   ├── 单行完整标题（普通片段 + 深色高亮片段）
│   └── 有纹理的黄色高亮层（从下往上展开）
├── support-text（渐显并沿轻微弧线从下往上贴入）
└── body-paragraph（首行缩进两格，整段按字符逐步生成）
```

## 数据能力

- `groups`：场景级父级模块，包含一组元素 ID 和自己的位移、透明度等关键帧。
- `segments`：一个标题元素内部的多个文字片段，各片段可以有不同颜色，但共享同一个排版与进场动画。
- `revealMode: characters`：按 `reveal` 进度截取字符串，实现一整段文字按字符生成。
- `textIndent`：正文首行缩进，以 `em` 为单位。
- `texture`：高亮层使用可配置的 CSS 纹理，不再只是纯色矩形。

## 时间关系

- 第 0–22 帧：`text-group` 从左侧向右进入并逐渐稳定。
- 第 2–26 帧：完整主标题在同一行内从左向右显现。
- 第 0–18 帧：黄色高亮先以完整细线状态进入，再从底部向上展开，与主标题处于同一时间窗口。
- 第 13–31 帧：辅助文字沿左下到右上的浅弧线贴入。
- 第 18–41 帧：正文作为一个首行缩进的段落按字符生成。

## 验收标准

- 标题在结构和视觉上是一整行，不再由两个独立标题动画拼接。
- 整个文字组有统一的从左向右进场运动，子模块不会显得各自摆放。
- 黄色高亮具有轻微明暗纹理，并从下往上展开。
- 辅助文字的路径不是一条直线，而是可从逐帧画面看出的浅弧线。
- 正文是一个段落，开头缩进两格，并按字符数增长；不再拆成五行分别显现。
- 仍保持 1280×720、30 FPS、42 帧，最终无水印和底部口播字幕。
- JSON 校验、TypeScript 检查、Remotion 渲染、开始/中间/结束帧及原片并排对照全部通过。

## 第十一版连续性修正

第十版虽然已经建立父级 `text-group`，但父级横移仍使用 4 个中间关键帧，并对每一段重复应用 `out-cubic`。每段都会先快速移动再减速到关键点，视觉上表现为“走一下、停一下、再走”。第十一版将父级横移改为第 0 帧 `x=-30` 到第 22 帧 `x=0` 的单段线性插值，每帧固定前进约 1.363636% 画布宽度。高亮的 `y` 和 `scaleY` 也各自收敛为一次连续插值；辅助文字保留路径点，但位置轨道改为线性连接，避免在每个路径点重复减速。
