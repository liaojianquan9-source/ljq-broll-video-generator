# 单句差值标题 + 独立黄色底模板设计

## 目标

标题“冲击全球市场的Kimi K3，到底有多强？”是一个完全连续的文字元素。它只有一份内容、一种白色源颜色、一套字体度量和一条连续的 `jump-in` 入场序列。黄色区域是第二个、独立的背景元素。标题不认识 `Kimi K3`，也没有普通区、高亮区或任何字符样式分段。

## 结构

当前标题模块由两个顶层元素组成：`main-title` 和 `title-highlight-bg`。`main-title` 使用单个 `content` 字符串、白色源颜色和 `mixBlendMode: "difference"`，本模板不使用 `segments`。`title-highlight-bg` 使用自己的矩形位置和动画，不与某个词建立语义绑定。其他模板仍按实际参考画面判断是否需要文字分段。

## 动效

整句字符按照一个连续索引播放“跃进”。差值混合统一作用于整个标题图层：文字压在深色背景上时显示为白色，压在黄色底上时自动变成深色。标题本身从未被改色。父组同时带着标题和黄色底横向进入；黄色底自身只负责从底边细线向上展开和透明度恢复。

## 修改与质检

模板的文字、字体、位置和时序都保存在同一个 JSON。更换标题时，只修改 `main-title.content`；黄色底的位置可独立调整。每次渲染至少检查起始帧、中间帧和结束帧，重点确认：场景中不存在标题 `segments`、黄色底扫过时同一个字自然变色、黄色底始终在文字后方、结束帧没有溢出画布。
