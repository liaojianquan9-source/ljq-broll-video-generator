# 保真质量门

## 必须检查

- 来源哈希与案例内副本一致；
- 渲染宽高、fps、视频帧数与合同一致；
- 源音频是否按案例约定保留；
- 生产资产只来自案例 `assets/`，参考帧、Contact Sheet、差异图和 `evidence/`、`validation/` 文件未进入运行时可见层；
- 普通文字、数字、参数、标题、线条和框是 live text、SVG 或可编辑形状，未使用截图、视频裁片或 alpha 贴图；
- 每类可替换元素通过替换冒烟测试：更换长短文案、数字位数和媒体宽高比后不残留原像素；
- 每个排版场景的落定帧分别通过元素、主体轮廓、边界、比例、裁切、层级、遮挡、字体轮廓和静态材质检查；
- 入场、强调、退场、逐字动画、整体镜头与转场的关键帧逐元素核对；
- 实际运动窗口没有无意重复帧、意外反向、中途近停后再跳或速度尖峰；
- 全片是否存在黑帧、闪帧、尾帧缺失、媒体错误或非确定性；
- 所有无法唯一还原的地方是否声明置信度或已知差异。

## 指标的边界

逐帧平均绝对 RGB 差异可帮助找到最差帧，但独立重建的抗锯齿、字体渲染和编码会产生大量无害像素差。没有跨案例通用的通过阈值。必须把数值与并排图、叠放图和实际播放结合判断。

像素差低不代表案例可复用。若参考截图直接进入成片，即使 MAD 更低也判失败。用户明确排除的人物或 A-roll 区域应建立比较遮罩，只验证该区域是否按约定为空白或透明，不能让它主导 B-roll 元素的视觉指标。

连续性只在元素或镜头实际运动的窗口内检查；明确停留、黑场和设计性的停顿不算卡顿。必要时把相邻帧差与元素几何位置序列同时保存，避免把编码噪声误判为运动。

## 修正优先级

优先级从高到低：错误来源/时间线；缺失或重复元素；主体几何与层级；锚点和整体运动；主要时间行为；字体占位与合成；次要纹理和编码。不能用模糊、噪点或复杂特效遮盖上游结构错误。

## 证据保存

初版为 pass 0。每次 QA 保存独立目录，避免重跑覆盖。通过时仍保留比较报告；失败时 issue 必须包含 owner、severity、observation、evidence 和可选 targetId。
