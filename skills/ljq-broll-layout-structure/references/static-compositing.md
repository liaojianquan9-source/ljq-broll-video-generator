# 静态视觉判断与合成

本文件由 layout 阶段维护，是布局、总控和 QA 共用的静态视觉判断规则。选帧和元素结构见 [visual-grammar.md](visual-grammar.md)；动态行为围绕已确认的静态终点取证。

## 判断顺序与完成证据

每个场景使用同一落定帧、同一画布和排除范围，按以下顺序比较 source/render/comparison still：

1. 画幅、裁切、视觉中心，以及主体之间的大小比例、占屏面积和留白；
2. 元素的实际可见边界、位置、对齐、遮挡和层级；
3. 主色家族、各颜色的视觉角色及面积关系；
4. 字体轮廓、字面比例、基线、换行和字距；
5. 渐变、描边、阴影、辉光、立体厚度和纹理。

先解决前项的显著偏差，再调整后项。细节丰富不能抵消比例或配色关系错误。每个场景的 observation 写明已核对的关系、证据路径和剩余差异；脚本运行成功或比较图存在，只证明产物生成。

## 实际可见边界

- 同时区分布局容器、主体实际像素边界（文字为 ink bounds）和阴影/辉光延伸边界。容器的 width/height、字号或图片文件尺寸不能代替主体边界。
- 在最终加载的字体、字重、换行和变换下测量 ink bounds；图片按有效内容或 alpha 边界测量。记录测量口径，比较图使用同一口径。
- 主体比例与占屏关系以实际可见内容为依据；组内还要核对数字/单位、标题/说明、图片/文字等相对尺度。
- 用画布百分比保存主边界和锚点，保留出画与裁切。容器数值需要与视觉边界不同的，在元素证据中解释偏移；不要为了让数值一致改变构图。

## 主色与颜色角色

先从参考落定帧记录主色家族、前景/背景/强调/材质高光的角色，以及主要色块的面积和明暗关系，再确定默认主题 props。复刻默认值保持这些关系；色相、亮度、对比度和饱和度可以为贴近参考作轻微校准。

例如，参考为蓝白主调时，局部反光、阴影或纹理色不等于新增主色，默认复刻应保持蓝白关系；其他参考按其自身主调建立基准。改变主调属于用户明确要求的变体。最终静帧和动态审阅使用参考默认主题，用户另有指定时以其指定主题为基准。

## 元素分析：共享属性与专属属性

拆元素、填写属性或解释合成关系时，必须读取[element-taxonomy.md](element-taxonomy.md)。它维护对象分类、共享/专属属性、蒙版处理链及写入合同的方法；本文件只维护视觉判断优先级。

## 蒙版与效果顺序

按[element-taxonomy.md的蒙版关系](element-taxonomy.md#蒙版是关系不是另一种素材格式)登记内容与遮罩，并在相同底图下比较候选处理链的可见结果。若效果只有换成另一张底图才显得正确，先核对底图/混合关系；用户指定白底等审阅处理时，将其与源画面配色区别记录。

## 观察、测量与推测

- `measured`：直接像素/几何测量，并保留测量口径。
- `observed`：清晰帧可观察的视觉事实，尚未数值拟合。
- `inferred`：原软件、混合模式、图层堆叠或参数存在多种解释；列候选与置信度。
- `default`：为可编辑实现选择的保守值，不宣称来自原片。

压平视频一般不能唯一反推制作软件、插件、精确参数或混合模式。在相同底图和颜色下，对少量候选模式做 still 对比；先匹配最终视觉。差异来自素材或色彩管理时回到相应原因，避免无边界遍历模式。

## 字体与可编辑边界

中文标题、数字、单位、拉丁字母和手写标注分别匹配。以原文案渲染候选，先校准字号、字重、字距、行高与基线，再小范围调整 scaleX；大幅压缩通常说明候选不合适。

比较外轮廓、负空间、端点、数字开口、衬线和字面比例，保留 Top 3 并排或叠放证据、字体来源/许可、渲染参数和置信度。只有有充分证据时才声称精确识别；用户认可视觉结果也不等于确认了原始字体或制作参数。

普通文字、数字、参数、线条、框和遮罩使用 live text、SVG、CSS 或可编辑组件。原帧、截图、Contact Sheet、文字裁切和比较图只用于取证；禁止把截图或 alpha 字形贴片作为运行时覆盖层来伪装可编辑或字体匹配。

## 静态 appearance 与动态 effects

落定后持续存在的渐变、受光、描边、阴影、辉光、厚度和纹理归 layout 的静态 appearance；随时间变化的扫光、入场模糊、拖影、闪光和效果强度曲线归 motion。持续底值和动态增量分别记录，动态收束回到已确认静态值。

名称不能决定归属：光、模糊或纹理在连续帧中是否变化才是证据。静态阶段先完成落定结果；动效阶段保留已确认的几何、配色和材质终点。

## 替换冒烟与视觉验收

替换冒烟检验 props 是否真实生效、原字形/旧素材/旧效果轮廓是否残留，以及替换后的布局风险；参考默认 still 检验复刻保真。两类证据分别命名和记录。

异色测试（例如蓝白改为粉橙）只证明主题可替换，不能作为正式配色或美学验收。完成测试后恢复默认 props 再做最终静帧和动态审阅。

换字后出现局部重叠、溢出或尺度失衡时，在 observation 中记录元素、触发文案和影响。没有旧字形残留只证明替换机制成立，不能写成“完全适配”。用户明确接受的次要排版问题保留已知差异和接受范围，按其优先级处理；用户未接受且影响主要阅读时，回到布局修正。
