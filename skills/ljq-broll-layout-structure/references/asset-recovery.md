# 素材恢复与裁切判断

## 先区分三个事实

1. 素材文件是否完整：`complete`、`visible-only`、`unknown`。
2. 可见区域为什么变少：`viewport-clip`、`container-mask`、`asset-crop`、`none`。
3. 素材从哪里来：`original`、`found`、`extracted`、`recreated`。

这些字段不能互相替代。一个完整 PNG 可能被画布裁切；一个 visible-only 提取物也可能没有任何运行时 mask。

## 恢复顺序

先服从用户对源帧的使用约束。若所有原帧/截图只准取证，下面的提取分支关闭，连非文字物体和纹理也不能从源帧裁成生产资产；使用用户独立资产、可核对来源的素材或可编辑近似，并记录剩余差异。

- 优先使用用户提供或案例原始素材。
- 能从源帧无歧义抠出的元素保存到 `assets/extracted/`，并保留提取帧证据。
- 能用标准 HTML/CSS 精确表达的几何形状和文字可以 `recreated`。
- 群内协作包或外部素材只有在获得使用许可后才能进入公开案例，并在第三方说明中记录来源。
- 不用生成式扩图补造不可见区域，也不把重绘素材标成 original。

外部素材保留实际来源页、许可/使用条件、原文件与转换说明；真实月面等素材只是本案可用的替代，不是所有复刻任务的默认资产库。素材来源可证明，也不代表坑纹、光照或镜头与原片精确一致。

## 文字与参考帧硬边界

- 普通文字、数字、参数、标题、线条和框必须实时重建。参考帧裁切、视频帧、带 alpha 的文字抠图都不能作为这些元素的生产资产。
- `evidence/` 与 `validation/` 中的文件只用于判断和比较，不能被复制到 `remotion/public` 后作为可见层使用。
- 固定官方字标若只有图形文件，可登记为 `type: image`、`replaceable: false`；用户要求可换字时不得使用这个例外。
- 可提取的照片、实拍物体、纹理和图标保存到 `assets/extracted/`，并通过媒体 prop 保持可替换。

静帧相似度不能推翻以上边界。用参考像素覆盖重建元素即使差异更小，也会让案例失去复用价值。

## 越界元素

若元素只是放在画布边角、部分看不见，优先保留完整素材和超出画布的真实 bounds，使用 `viewport-clip`。不要先裁掉素材再把它误判为 `asset-crop`。

## 提取限制

背景复杂、运动模糊、被遮挡或隐藏面积过大时，提取结果只能是 `visible-only` 或 `unknown`。把缺口记为已知差异，避免为追求“完整”而改变原构图。
