# 落定帧排版语法

## 目标

落定帧回答：有哪些元素、在哪里、多大、怎样裁切、谁遮挡谁、静态外观怎样、哪些内容以后可替换。它是动效的终点状态，不是运动过程。

## 选帧

按顺序判断：主要元素完成入场；阅读关系建立；未开始退出或转场；瞬时模糊和闪光最少；信息最完整。记录准确帧号、时间码、证据类型和置信度。

## 坐标与边界

- 继承源宽高、方向和 fps，不强制套 16:9。
- `bounds` 使用画布百分比 `[left, top, width, height]`，允许 left/top 为负或宽高越出画布；实际可见边界与容器的测量口径按 [static-compositing.md](static-compositing.md#实际可见边界)。
- `anchor` 是元素内部 0..1 的锚点。
- 细线、文字基线可在 Remotion 中做局部像素微调，但合同仍保存百分比主边界。

## 稳定元素 ID

- ID 使用小写连字符，例如 `hero-title-01`、`subject-video-01`。
- 同一语义元素从布局到动效、实现和 QA 保持同一 ID。
- 同时移动的内容建立命名组，子元素仍保留可替换内容。
- 下游发现拆分错误时退回布局阶段，不创建平行 ID。

## 拆分原则

满足任一条件才独立：下次要替换；需要独立定位/裁切/样式；形成独立遮挡；后续独立运动；定义容器或视觉中心。实拍内部的普通人物和桌面可留在一个视频层，除非要抠像或替换。

## 文字

保留真实文案作为基准，并把可替换内容暴露为 props。重点测量字块总宽、行高、换行、对齐、字重和基线。字体只能列候选时不要宣称精确识别。

## 视觉复核

源落定帧与 Remotion still 做并排和半透明叠放。核对比例、配色、字体/材质、蒙版或替换适配时，必须使用 [static-compositing.md](static-compositing.md) 的判断顺序与完成证据。这里只检查静态终点。
