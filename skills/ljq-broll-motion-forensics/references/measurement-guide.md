# 动效测量指南

## 四类核心证据

先固定零基逻辑帧、原视频时间与文件编号映射。例如FFmpeg从`frame-000001.png`开始时，该文件对应逻辑frame 0；稀疏抽帧还要保存step。边界前后逐帧检查，不能从文件尾号直接推断时码。

1. **什么在动。** 比较多个有纹理区域。多个元素轨迹一致时优先建父组或 `@camera`，不要逐层复制同一运动。
2. **平移还是旋转。** 同一对象上离轴距离不同的两个纹理块，若远端位移明显更大，才支持绕近端旋转；两端位移接近更像平移。
3. **什么时候出现。** 记录 firstVisible、settledFrame、endFrame。不要把压缩噪声第一次变化当作视觉出现。
4. **怎样揭示。** 擦除会出现沿路径移动的清晰边界；淡入会让多数采样点的强度一起增长。只看二值占用容易误判。

先拟合共同镜头，再比较各元素剥离camera后的残差。稳定背景纹理、边缘或框角节点交叉验证同一中心与尺度；入场伸长的整个数字框不宜直接当camera标尺，可换用已收束的单字或固定框角。线条随camera缩小进入画布，可能只是视口裁切，不等于有独立绘制动画。

离屏圆体只有短弧时，优先记录固定扫描线上的可见边沿及误差；短弧圆拟合不能可靠还原完整半径，固定扫描线的轮廓点也不是同一个物体纹理点。替代素材最终参数由已批准的可见比例校准。

## 文字

逐字符出现顺序单调，可能是打字或方向擦除；短窗口内非单调散开，可能是同时散射进入。两者都只能描述可见行为，不能据此断言原软件。

逐字动画需分别测量：字符顺序、stagger、主字位移、模糊、纵向拉伸、残影层数、残影间距和落定后的收束帧。类似“叠影”的预设名可以帮助命名，但层数和参数必须从原片取证。

持续存在的顶部受光、描边、金属渐变和基础辉光属于静态材质；只在入场期出现的额外辉光、运动模糊和残影属于动态。两者不能写进同一个最终归零的效果轨。

## 元素分轨

在 motion JSON 前先写逐元素行为表。对每个 ID 独立回答：

- 首次可见、主要落定和退出帧；
- 位移、缩放、旋转、透明度、模糊、遮罩与亮度中哪些变量实际变化；
- 动画锚点和父组；
- 是否只共享整体镜头，还是元素自身也在动。

同一时刻出现的元素可能分别采用上移、原位显影、逐字掉落和斜向擦开。没有共同轨迹证据时不得合并成统一步骤。

## 连续曲线

密集帧测量用于拟合，不用于建立一串重复缓动的短段。schema 1.2 的单一连续空间动作用两个 endpoint keyframe，并在轨道对象上声明 `interpolation: linear|bezier`和可选的四点 `bezier`。中间测量点保存到 evidence，不放进可执行轨道里重启 easing。

确有“入场—过冲—回弹”等语义阶段时，拆成独立 motion 并保证连接处连续；确有反向或设计性停留时，使用 `allowReversal` 或 `allowHoldFrames` 显式记录，不让分析器把意图当成卡顿。

整体镜头缩放单独测量，至少包含开始、明显变化、中段、接近落定和完全落定后的帧。若画面到后段仍在缓慢收束，曲线终点不能提前放在视觉变化刚变小的位置。

运行主 Skill `analyze-motion-continuity.mjs <case-dir>` 生成相邻帧几何增量证据，再观看完整渲染排除编码噪声与设计性停留。活动区出现无意重复帧、中途近停后重新变大、意外反向或尖锐速度跳变时，视为卡顿并返回修正。明确停留和黑场不在活动窗口内。

## 失效条件

- 区域几乎纯色或渐变：相位相关无法锁定。
- 元素被其他层穿过：该段轨迹属于遮挡污染。
- 缩放或旋转过大：固定框平移测量会漂移。
- 细线被降采样消失：必须使用全分辨率帧。
- 源为可变帧率：先以解码帧序列为合同，不直接相信容器声明帧数。

失效时降低置信度、换区域、缩短时间窗或使用人工关键帧；不得用看似精确的小数掩盖不可靠证据。

## 合同单位

- `x`、`y`、`blurPx`、`distancePx`：输出画布像素。
- `scaleX`、`scaleY`：无单位倍率，1 为落定值。
- `rotationDeg`、`hueRotateDeg`：度。
- `opacity`、`reveal.progress`：0..1。
- `frame`：从 0 开始的整数解码帧索引。
