# 从动效证据到可编辑实现

把motion接入已批准的Remotion、修改动态文字/蒙版或审查合同与runtime一致性前读取。测量依据见[measurement-guide.md](measurement-guide.md)，静态基准保护与工具副作用见[执行手册](../../ljq-broll-replica/references/execution-playbook.md)。

## 先验证实际入口

沿`case.files.composition`查看真实imports与组件树。目录里存在通用runtime，不代表当前composition使用它。为本次使用的transform、effects、reveal和textAnimation列“合同字段→实际函数/组件→探针帧”的简表；未消费的字段就是未实现。

预设名只是兼容标签，不能替代可见行为。伸长字形、细轮廓或暗字面不自动证明多层ghost；未观察到重复完整字形时明确无detached ghost。若只能用兼容标签表达无残影的收束，应写清参数与实际执行分支，并以渲染确认；不要宣称该runtime实现了同名预设的所有功能。fade不能登记成有径向前沿的wipe/mask。

## 变换与时间

| 条件 | 实现与验收 |
| --- | --- |
| 多场景共享`@camera`或`@transition` | 同时限定场景scope与挂载窗口。采样函数夹持首/尾值时，endFrame不自动让变换失效；跨场采样探针必须确认前后镜头末值没有相乘 |
| 场景交叉淡化 | 保留交叠期两个独立场景层；主要场景边界与最后可见帧分开。硬切则由可见窗口直接切，不给每个子元素发明退出 |
| 静态旋转＋沿父坐标轴平移 | 动态位移置外层，静态旋转置内层；或显式控制矩阵顺序。检查3个中间帧，竖直运动不能被rotate带成斜向 |
| 镜头持续拉远但静帧已批准 | 以批准frame的camera值为1校准，前后曲线仍覆盖真实活动窗口；局部入场落定、静态参考、镜头停止不是同一时刻 |
| 静态材质＋动态特效 | 保留底值，透明度按图层关系相乘、额外模糊按定义叠加；动态增量回到0/1后基础辉光、纹理、描边仍在 |
| schema能写但runtime不支持 | 先补对应实现及小窗口测试，或记录可见近似与能力缺口；不凭schema校验成功宣称实现成功 |

## Live文字和图片

最终字体加载后再量文字。可用Canvas `measureText`/`actualBoundingBox*`取得实际字面，生产画面用SVG `<text>`、DOM text、live `<use>`与mask。字体家族、字重、字距或文案改变时重新量；等待字体与测量完成再让still输出，避免系统fallback进入证据。

纹理定位、裁切和字形遮罩分别可追踪；换字后纹理mask必须来自新字形。图片以有效内容边界校准占比，角落物体保留完整资产与viewport裁切。替代素材的轮廓/坑纹不同，运动数值可能需按其可见弧线重新校准；不能把固定屏幕扫描线上的弧边当固定纹理点。

## 逐字替换的结束帧

先选定有效字符划分方式，并在文案变化时重新计算字符边界与延迟。若保持时间窗`[start,end]`、字符数`n`、最短单字时长`d`，先确认窗口可容纳`d`，再限制`effectiveStagger ≤ (end-start-d)/max(1,n-1)`；单字时长使用剩余窗口。字数太多或组合字形需要更复杂分段时说明限制，不能悄悄延长用户总时长。

至少渲染首次预期可见帧、前一帧、end-1及end。起始关键帧opacity=0时，实际首次非零可能晚一帧；记录观察口径，不能把曲线起点直接称为精确首次可见。end帧切回完整静态绘制前，最后一字应已收束，不能从未出现突然全显。动态时间适配与静态长文案重叠分别验收。

## 最小验证集

每条独立行为覆盖开始、明显变化、中段、近落定、落定后；切点、反向和转场覆盖相邻帧。用单次bundle/浏览器批量导出；每场另保留静态模式回归。检查镜头作用域、运动方向、残影数量、字形/遮罩、基础效果、替换终帧，再完整渲染。

合同连续性分析只覆盖它实际读的空间轨，不覆盖逐字逻辑、透明度、模糊和浏览器组合矩阵。应检查窗口数量；零窗口的pass不能证明有动画的案例连续。完成标准为字段有执行映射、静态基准未回退、代表探针和长替换终帧实际看过，且全片技术/视觉检查按QA另行完成。
