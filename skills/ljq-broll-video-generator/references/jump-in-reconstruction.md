# `jump-in` 文字入场预设

## 大白话说明

整行文字最后的排版始终不变。动画开始后，每个字从它最终位置的右下方飞进来，前面的字先动，后面的字紧跟着动。单个字会稍微越过最终基线，然后回落并停稳。

## 运动规律

- 字符错峰基准：2/30 秒。
- 单字位移基准：26/30 秒。
- 单字淡入基准：19/30 秒。
- 整行设定总时长后，上述三者按文字数等比压缩，保证最后一个字在总时长结束时停稳。
- 不使用缩放、旋转或模糊。
- 位移幅度默认为 0.26，是用实际 1920×1080 导出片校准后的屏幕换算值。

## JSON 调用

```json
{
  "textEntrance": {
    "preset": "jump-in",
    "startFrame": 0,
    "durationInFrames": 36,
    "intensity": 0.26
  }
}
```

`intensity` 可以不写。低于 0.26 会更克制，高于 0.26 会增加起跳距离。

## 校准证据

参考视频：用户提供的“跃进”文字动画导出片，1920×1080、30fps、15 帧。参考源文件不随仓库分发。

| 帧 | 原版亮度外接框 | Remotion 校准版 | 左上角误差 |
|---|---|---|---|
| 2 | `(446, 553)` | `(454, 556)` | `(8, 3)` |
| 3 | `(423, 536)` | `(430, 538)` | `(7, 2)` |
| 4 | `(388, 512)` | `(395, 514)` | `(7, 2)` |
| 6 | `(334, 482)` | `(340, 485)` | `(6, 3)` |
| 10 | `(311, 480)` | `(317, 480)` | `(6, 0)` |
| 15 | `(311, 488)` | `(317, 489)` | `(6, 1)` |

这里的误差同时包含字体差异和视频压缩误差，因此用于证明运动轮廓一致，不表示字体完全一致。
