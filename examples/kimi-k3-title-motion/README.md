# 案例二：Kimi K3 标题动效

这是早期的“连续参考片段 → Remotion 可编辑标题动效”案例。画面包含整组左移入场、黄色高亮从下展开、差值混合标题、辅助文字和正文逐步出现。

## 文件

- [可编辑 Scene JSON](scene.json)
- [生成视频](generated.mp4)
- [原素材 / 生成效果上下对比](original-vs-generated-stacked.mp4)

上下对比视频上半部分为原素材，下半部分为生成效果；这是用户提供并确认需要纳入仓库的版本。

## 做到了什么

- 从连续片段中观察 42 帧的主要时序关系。
- 把标题组的整体运动和内部高亮、文字生成分开表达。
- 使用单一标题图层与 `difference` 混合模式，让文字跨过黄色底时自然改变明暗。
- 保留独立 Scene JSON、单独生成成片和直接比较证据。

## 已知差异

- 字体无法确认到原片的精确字体，字宽、字重和字距仍有偏差。
- 标题、高亮和正文的空间位置尚未达到原片精度。
- 跃入、模糊、残影和高亮质感仍比原片生硬。
- 当前版本证明了结构与技术路线可行，但还没有达到新版高保真验收标准。

这个案例将作为后续“落定帧校准 → 动效取证 → 最多两轮定向修正”的主要回归样本。
